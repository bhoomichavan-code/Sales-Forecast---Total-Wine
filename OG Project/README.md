# OG Project — original capstone files

These are the original files from the BUDT758W capstone, kept for reference. They
are **not** the deliverable; the reworked, reproducible project lives in
`../cabernet-sales-forecast/`.

Contents:
- `Business Framing Document - BUDT758W Capstone.pdf` — the assignment brief (CRISP-DM, deliverables, timeline).
- `TW_Master_Internal_Data.csv` — the raw internal sales + store + demographics master.
- `TW_Final Test Data.csv` / `.xlsx` — the unlabeled competition hold-out set.
- `master_modified.csv` — a pre-cleaned/feature-engineered version from the original work.
- `Cabernet Sauvignon (Internal Sales).xlsx`, `Cabernet Sauvignon (External Data).xlsx` — source workbooks.
- `Store Information.xlsx`, `Data Field Definitions.xlsx` — store metadata and the field dictionary.
- `Total Wines_Cabernet Sauvignon.pdf` / `.xlsx`, `Total Wine - Bhoomi Chavan.pdf` — earlier analysis/presentation artifacts.

The reworked project rebuilds everything from `TW_Master_Internal_Data.csv` in
code, so these originals are reference-only.
